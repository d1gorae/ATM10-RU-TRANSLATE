# ATM10 — неофициальный русский перевод

Проект предназначен для ATM10 (Minecraft 1.21.1, NeoForge). Это отдельный ресурс-пак: исходные файлы модов и оригинальные материалы не изменяются.

## Установка

1. Скачайте ZIP ресурс-пака из раздела Releases (публикация ещё не подготовлена).
2. Поместите ZIP в папку `.minecraft/resourcepacks`.
3. Включите пак в меню «Настройки → Наборы ресурсов».
4. Выберите русский язык Minecraft.

## Статус

Перевод находится в разработке. Текущая ветка не является завершённым релизом.

- В репозитории: **46 языковых файлов** для 46 namespace.
- Переведено: **около 444 строк локализации** (число ключей; перед релизом будет выполнен полный повторный подсчёт).
- В исходной инвентаризации найдено 405 английских JSON-файлов (402 уникальных namespace).
- В старом исходном репозитории найдено 262 русских JSON-файла в RU_RESOURCE_PACK (256 уникальных namespace).
- После сопоставления исходных русских файлов с английскими и учёта текущего репозитория остаётся **108 namespace без русского файла**. Пять английских файлов пустые; **103 непустые локализации** ещё нужно проверить на наличие пользовательского текста и перевести при необходимости.
- FTB Quests: найдено 67 английских файлов глав и 63 русских. По именам файлов отсутствуют русские версии глав: `aether`, `apotheosis_gear`, `auroral`, `create_addons`, `deeper_and_darker`, `extended__advanced_ae`, `neo_vitae`; три русских файла не имеют английского совпадения по имени: `rust_free_and_oiled`, `steam_age`, `the_electric_age`.
- Дополнительная проверка общих языковых файлов FTB Quests: `chapter_group.snbt` содержит все 13 ключей с обеих сторон; `chapter.snbt` — 78 английских и 69 русских записей (12 отсутствуют в русском, 3 есть только в русском); `reward_table.snbt` — 51 английскую и 44 русские записи (7 отсутствуют в русском). `file.snbt` содержит только название сборки `All The Mods 10`, которое не требует перевода. Пустые подписи `image.*.title` в главах также не требуют перевода.
- Содержимое совпадающих файлов глав FTB Quests ещё нужно сверить по идентификаторам заданий, а не только по именам файлов. Поэтому существующий русский набор нельзя считать полностью проверенным.

## Правила качества

- Не менять ключи JSON.
- Сохранять плейсхолдеры (`%s`, `%d`, `%%` и позиционные варианты).
- Сохранять форматирующие коды Minecraft (`§`).
- Сохранять технические идентификаторы, namespace и названия API.
- Не изменять SNBT до отдельной проверки структуры и ссылок FTB Quests.
- Каждый перевод проверять сравнением ключей, плейсхолдеров и форматирующих кодов с оригиналом.
