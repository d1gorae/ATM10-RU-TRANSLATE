# ATM10 RU

Русская локализация **All the Mods 10** · Minecraft 1.21.1 · NeoForge.

## Скачать и установить

**[Скачать последнюю версию](https://github.com/d1gorae/ATM10-RU-TRANSLATE/releases/latest)**

1. Закройте Minecraft.
2. Распакуйте содержимое ZIP-архива из релиза в папку сборки ATM10 — туда, где находятся `mods`, `config` и `saves`.
3. Подтвердите слияние папок и замену файлов.
4. Запустите игру и включите **ATM10 RU** в «Настройки → Наборы ресурсов».
5. Выберите язык «Русский».

Перед заменой собственных файлов FTB Quests сохраните резервную копию папки `config/ftbquests/quests/lang/ru_ru`.
