# ATM10 — русский перевод

**Неофициальная русская локализация All the Mods 10** для Minecraft 1.21.1 / NeoForge.

Проект объединяет перевод игровых интерфейсов и модов, а также локализацию FTB Quests. Для игроков будет подготовлен **один общий архив**: его нужно распаковать в папку установленной сборки ATM10, сохранив структуру каталогов. Файлы локализации попадут в нужные места, а при совпадении имён система предложит заменить существующие.

> Репозиторий содержит исходные материалы проекта. Для установки используйте единый архив из раздела Releases, когда он будет опубликован.

## Установка

1. Полностью закройте Minecraft.
2. Скачайте единый архив `ATM10-RU-Full.zip` из раздела [Releases](https://github.com/d1gorae/ATM10-RU-TRANSLATE/releases).
3. Откройте папку именно вашей сборки ATM10 — ту, внутри которой находятся каталоги `mods`, `config` и `saves`.
4. Распакуйте **всё содержимое архива прямо в эту папку**.
5. Если Windows спросит о слиянии папок или замене файлов, подтвердите действие.
6. Запустите Minecraft.

**Важно:** перед распаковкой рекомендуется сделать резервную копию папки `config/ftbquests/quests/`. Архив заменит совпадающие файлы локализации FTB Quests. Не распаковывайте архив в папку `mods`, `resourcepacks` или в отдельную вложенную папку — только в корень экземпляра ATM10.

### Активация перевода модов

Часть переводов устанавливается как обычный ресурс-пак Minecraft. Распаковка общего архива поместит его в папку `resourcepacks`, но Minecraft может не включить новый ресурс-пак автоматически.

Если после установки переводы модов не появились:

1. Запустите игру.
2. Откройте **Настройки → Наборы ресурсов**.
3. Переместите ресурс-пак ATM10 RU в активные.
4. Подтвердите изменения.
5. В настройках языка Minecraft выберите **Русский**.

Перевод FTB Quests устанавливается в конфигурацию сборки отдельно от обычных языковых файлов и не требует активации через меню наборов ресурсов.

## Где находится папка сборки

Нужна папка экземпляра ATM10, в которой лежат `mods`, `config` и `saves`.

- **Prism Launcher:** нажмите правой кнопкой мыши на экземпляр ATM10 и выберите **Папка** / **Открыть папку**.
- **CurseForge:** откройте профиль ATM10, раскройте меню профиля и выберите **Открыть папку**.
- **Другие лаунчеры:** воспользуйтесь функцией открытия папки экземпляра или игровой директории.

Путь к папке у каждого пользователя может отличаться.

## Для участников проекта

Исходные файлы хранятся в репозитории отдельно от пользовательского архива:

- `assets/` и `pack.mcmeta` — исходная структура ресурс-пака Minecraft.
- `FTBQUESTS/ru_ru/` — локализация FTB Quests в формате SNBT.
- `GLOSSARY.md` — единая терминология проекта.
- `INVENTORY.md` — инвентаризация модов и namespace.
- `PROJECT_HANDOFF.md` — состояние работ и точка продолжения.
- `NO_RU_JSON_AUDIT.md` — результаты проверки namespace без одноимённых русских JSON.

Английские оригиналы доступны отдельно и используются только для чтения: [ATM/LANGUAGES_EN_US](https://github.com/d1gorae/beamng-road-reference/tree/main/ATM/LANGUAGES_EN_US).
