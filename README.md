# ATM10 — неофициальный русский перевод

Проект предназначен для ATM10 (Minecraft 1.21.1, NeoForge). Это отдельный ресурс-пак: исходные файлы модов и оригинальные материалы не изменяются.

## Установка

1. Скачайте ZIP ресурс-пака из раздела Releases (публикация ещё не подготовлена).
2. Поместите ZIP в папку `.minecraft/resourcepacks`.
3. Включите пак в меню «Настройки → Наборы ресурсов».
4. Выберите русский язык Minecraft.

## Актуальная инвентаризация (ATM10 8.5, 04.11.2026)

Сверка выполнена с официальным репозиторием [AllTheMods/ATM-10](https://github.com/AllTheMods/ATM-10), ветка `main`, версия сборки **8.5** (в официальном `CHANGELOG.md` указана дата 04.11.2026). Список установленных модов взят из `config/crash_assistant/modlist.json`.

- В официальном списке: **491 записей**, **490 уникальных mod ID** (один ID встречается повторно).
- В этом ресурс-паке сейчас: **296 файлов `ru_ru.json`**.
- По прямому совпадению mod ID с namespace локализаций покрыто **283 из 490** модов.
- **206 mod ID** пока не имеют одноимённого `assets/<namespace>/lang/ru_ru.json`; это список кандидатов на проверку исходных `en_us.json`, а не утверждение, что все эти моды обязательно требуют перевода. У части модов может не быть собственного языкового файла, а некоторые строки могут приходить из другого namespace.
- `ftbquests` также отсутствует среди JSON-локализаций, но его SNBT-перевод намеренно отложен до самого конца проекта и в эту работу не включается.
- Ещё **13 namespace** есть в ресурс-паке, но не имеют прямого совпадения с mod ID текущего списка сборки: `borderless`, `cloth-config2`, `dynamic_fps`, `entityculling`, `evilcraftcompat`, `integrateddynamicscompat`, `integratedterminalscompat`, `irons_patreon_lib`, `lambdynlights`, `lollipop`, `moreculling`, `tempad_static`, `vulkanmod`. Их нельзя автоматически удалять: это могут быть библиотеки, алиасы, вспомогательные namespace или остатки другой версии.
- Полный список отсутствующих namespace и методика проверки: [INVENTORY.md](INVENTORY.md).

**Важно:** отсутствие файла русского перевода не равно отсутствию необходимости в переводе. Чтобы получить окончательный объём, следующий подэтап — проверить наличие `en_us.json` в каждом из 206 модов (или общий namespace, из которого мод берёт строки), затем посчитать ключи и отделить пустые/служебные языковые файлы от реального пользовательского текста. FTB Quests не трогать до отдельного финального этапа.

## Повторная смысловая проверка

Проверка переводов проводится не только по совпадению ключей: названия предметов и блоков сверяются с назначением, рецептами, описаниями и механиками соответствующих модов. Уже выполнены исправления терминологии в Ars Nouveau, Create: Enchantment Industry, Cobblegen Galore, DimStorage, GMUT, Immersive Energistics, MIFA и других локализациях. Семантическая вычитка всех файлов продолжается; текущий набор не объявляется завершённым.

## Правила качества

- Не менять ключи JSON.
- Сохранять плейсхолдеры (`%s`, `%d`, `%%` и позиционные варианты).
- Сохранять форматирующие коды Minecraft (`§`).
- Сохранять технические идентификаторы, namespace и названия API.
- Не изменять SNBT до отдельной проверки структуры и ссылок FTB Quests.
- Каждый перевод проверять сравнением ключей, плейсхолдеров и форматирующих кодов с оригиналом.
- Техническая повторная проверка текущих 70 JSON-файлов завершена: все файлы разбираются, наборы ключей совпадают с английскими оригиналами, расхождений в проверенных плейсхолдерах и кодах форматирования не найдено. Дополнительно выполнен поиск длинных строк, полностью оставленных на английском без кириллицы; таких точных совпадений не обнаружено. Это не заменяет смысловую проверку терминов и тестирование в игре.
