# ATM10 — неофициальный русский перевод

Полная русская локализация сборки **All the Mods 10** для Minecraft 1.21.1 / NeoForge. Перевод распространяется отдельным ресурс-паком: исходные файлы модов и английские оригиналы не изменяются.

## Статус проекта

**Переводческие работы завершены на 06.11.2026.** Закрыты все обычные namespace английского каталога, а также финальные специальные разделы FTB Quests и SNBT.

- Все обычные namespace из актуального дерева ATM/LANGUAGES_EN_US сверены с русскими файлами.
- Последние обычные namespace: xycraft_world (324/324 ключа) и yet_another_config_lib_v3 (26/26 ключей).
- FTB Quests: имена файлов совпадают для **67/67 глав**; главы и связанные SNBT-файлы прошли зафиксированный аудит.
- SNBT: проверено **20 файлов**, структура сбалансирована.
- В проверенных JSON нет зафиксированных пропусков/лишних ключей, дубликатов, несовпадений плейсхолдеров, форматирования или переносов строк.
- Полноценный запуск ATM10 и внутриигровое тестирование локализации **ещё не проводились**. Это следующий этап контроля качества.

Подробные результаты, перечни namespace, ограничения аудита и ссылки на коммиты: [PROJECT_HANDOFF.md](PROJECT_HANDOFF.md) и [INVENTORY.md](INVENTORY.md).

## Установка

Публикация готового ZIP в разделе Releases ещё не подготовлена. До выпуска ресурс-пак можно установить из исходников репозитория:

1. Скачайте репозиторий как ZIP или получите его через Git.
2. Убедитесь, что структура содержит каталог assets и файл pack.mcmeta в корне ресурс-пака.
3. Поместите папку ресурс-пака либо ZIP в .minecraft/resourcepacks.
4. Включите пак в меню «Настройки → Наборы ресурсов».
5. Выберите русский язык Minecraft.

Если структура архива после скачивания содержит внешнюю папку репозитория, в resourcepacks нужно поместить именно внутреннюю папку с pack.mcmeta, а не архивирующую папку уровнем выше.

## Инвентаризация сборки

Сверка состава модов выполнена по официальному репозиторию [AllTheMods/ATM-10](https://github.com/AllTheMods/ATM-10), ветка main, ATM10 **8.5**.

- В официальном списке: **497 записей**, **490 уникальных mod ID** (без NeoForge).
- В ресурс-паке: **399 файлов ru_ru.json**.
- По прямому совпадению mod ID с namespace локализаций покрыто **385 из 490** модов.
- **105 mod ID** не имеют одноимённого русского JSON. Это не означает, что каждому нужен отдельный файл: часть модов покрыта общими namespace, а часть не содержит пользовательских языковых строк.
- Ещё **14 namespace** в ресурс-паке не имеют прямого совпадения с mod ID.

Методика и результаты проверки кандидатов без одноимённого JSON приведены в [INVENTORY.md](INVENTORY.md) и [NO_RU_JSON_AUDIT.md](NO_RU_JSON_AUDIT.md).

## Терминология и качество

Основной источник согласованной терминологии — [GLOSSARY.md](GLOSSARY.md).

При проверке сохраняются:
- ключи JSON и технические идентификаторы;
- плейсхолдеры (%s, %d, %% и позиционные варианты);
- форматирующие коды Minecraft (§);
- переносы строк, специальные символы и значимые пробелы;
- названия брендов, API и имена собственные, если их перевод неуместен.

Проверка включала не только структуру файлов, но и смысловую вычитку строк с учётом механик и терминологии модов. Совпадение значения с английским оригиналом само по себе не считается ошибкой: некоторые имена и обозначения намеренно остаются без перевода.
