# ATM10 — неофициальный русский перевод

Проект предназначен для ATM10 (Minecraft 1.21.1, NeoForge). Это отдельный ресурс-пак: исходные файлы модов и оригинальные материалы не изменяются.

## Установка

1. Скачайте ZIP ресурс-пака из раздела Releases (публикация ещё не подготовлена).
2. Поместите ZIP в папку `.minecraft/resourcepacks`.
3. Включите пак в меню «Настройки → Наборы ресурсов».
4. Выберите русский язык Minecraft.

## Статус

Перевод находится в разработке. Текущая ветка не является завершённым релизом.

- В репозитории: **61 языковой файл** для 61 namespace.
- В 61 файле содержится **471 языковой ключ** (подсчёт по текущим JSON).
- В исходной инвентаризации найдено 405 английских JSON-файлов (402 уникальных namespace).
- В старом исходном репозитории найдено 262 русских JSON-файла в RU_RESOURCE_PACK (256 уникальных namespace).
- После сопоставления исходных русских файлов с английскими и учёта текущего репозитория остаётся **101 namespace без русского файла**. Пять английских файлов пустые; **96 непустых локализаций** ещё нужно проверить на наличие пользовательского текста и перевести при необходимости.
- FTB Quests: в текущей английской версии найдено 67 глав. Все 67 имён глав теперь представлены в `FTBQUESTS/ru_ru/chapters`; добавлены файлы `aether`, `apotheosis_gear`, `create_addons`, `deeper_and_darker`, `extended__advanced_ae` и `neo_vitae`. В трёх русских файлах нет совпадения по имени с английской главой: `rust_free_and_oiled`, `steam_age`, `the_electric_age`. Все шесть добавленных глав переведены по текущим английским источникам. Для каждой из них выполнено сравнение ключей: отсутствующих и лишних ключей нет, количество массивов описаний и скобок совпадает с оригиналом. Имена модов, названия API и служебная строка `AllRightsReserved` сохранены там, где перевод неуместен. Смысловая вычитка и проверка в игре ещё нужны.
- Ранее проведённая сверка 60 пар глав FTB Quests выявила расхождения версий: около 1 110 отсутствующих полей и 285 дополнительных русских полей. Новые шесть глав добавлены по текущим английским источникам с сохранением идентификаторов и структуры; общий повторный аудит всех 67 глав ещё предстоит. Неизвестные ключи и старые ID нельзя удалять без проверки.
- В общих языковых файлах FTB Quests: `chapter_group.snbt` содержит 13 ключей с обеих сторон; `chapter.snbt` — 74 английских и 67 русских названий (10 отсутствуют в русском, 3 есть только в русском); `reward_table.snbt` — 51 английское и 44 русских названия (7 отсутствуют в русском). `file.snbt` содержит только название сборки `All The Mods 10`, которое не требует перевода.
- FTB Quests использует отдельные SNBT-файлы в каталоге конфигурации сборки, а не обычные JSON-файлы ресурс-пака. Поэтому эти переводы нужно поставлять отдельно и не смешивать с `assets/<namespace>/lang/ru_ru.json`. До публикации FTB-части требуется синхронизировать ID с текущей английской версией, перевести новые строки и сохранить структуру SNBT.

## Повторная смысловая проверка

Проверка переводов проводится не только по совпадению ключей: названия предметов и блоков сверяются с назначением, рецептами, описаниями и механиками соответствующих модов. Уже выполнены исправления терминологии в Ars Nouveau, Create: Enchantment Industry, Cobblegen Galore, DimStorage, GMUT, Immersive Energistics, MIFA и других локализациях. Семантическая вычитка всех файлов продолжается; текущий набор не объявляется завершённым.

## Правила качества

- Не менять ключи JSON.
- Сохранять плейсхолдеры (`%s`, `%d`, `%%` и позиционные варианты).
- Сохранять форматирующие коды Minecraft (`§`).
- Сохранять технические идентификаторы, namespace и названия API.
- Не изменять SNBT до отдельной проверки структуры и ссылок FTB Quests.
- Каждый перевод проверять сравнением ключей, плейсхолдеров и форматирующих кодов с оригиналом.
- Техническая повторная проверка текущих 61 JSON-файлов завершена: все файлы разбираются, наборы ключей совпадают с английскими оригиналами, расхождений в проверенных плейсхолдерах и кодах форматирования не найдено. Дополнительно выполнен поиск длинных строк, полностью оставленных на английском без кириллицы; таких точных совпадений не обнаружено. Это не заменяет смысловую проверку терминов и тестирование в игре.
