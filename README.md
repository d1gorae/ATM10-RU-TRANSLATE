# ATM10 — неофициальный русский перевод

Проект предназначен для ATM10 (Minecraft 1.21.1, NeoForge). Это отдельный ресурс-пак: исходные файлы модов и оригинальные материалы не изменяются.

## Установка

1. Скачайте ZIP ресурс-пака из раздела Releases (публикация ещё не подготовлена).
2. Поместите ZIP в папку `.minecraft/resourcepacks`.
3. Включите пак в меню «Настройки → Наборы ресурсов».
4. Выберите русский язык Minecraft.

## Статус

Перевод находится в разработке. Текущая ветка не является завершённым релизом.

- Переведено: 10 языковых файлов для 10 модов.
- Переведено строк: 136.
- В исходной инвентаризации найдено 405 английских JSON-файлов (около 402 уникальных namespace).
- В старом исходном репозитории найдено 262 русских JSON-файла в RU_RESOURCE_PACK; их необходимо учитывать как уже существующие переводы, а не переводить заново.
- Для FTB Quests найден отдельный русский набор: 67 файлов SNBT, включая 63 файла глав. В английском наборе 67 файлов глав; семь названий глав отсутствуют в русском наборе, при этом есть три русских файла глав без совпадающих имён в английском наборе. Перед публикацией нужно отдельно сверить идентификаторы и актуальность этих глав.

## Правила качества

- Не менять ключи JSON.
- Сохранять плейсхолдеры (`%s`, `%d`, `%%` и позиционные варианты).
- Сохранять форматирующие коды Minecraft (`§`).
- Сохранять технические идентификаторы, namespace и названия API.
- Не изменять SNBT до отдельной проверки структуры и ссылок FTB Quests.
- Каждый перевод проверять сравнением ключей, плейсхолдеров и форматирующих кодов с оригиналом.
