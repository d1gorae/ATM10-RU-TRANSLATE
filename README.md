# ATM10 — неофициальный русский перевод

Проект предназначен для ATM10 (Minecraft 1.21.1, NeoForge). Это отдельный ресурс-пак: исходные файлы модов и оригинальные материалы не изменяются.

## Установка

1. Скачайте ZIP ресурс-пака из раздела Releases (публикация ещё не подготовлена).
2. Поместите ZIP в папку `.minecraft/resourcepacks`.
3. Включите пак в меню «Настройки → Наборы ресурсов».
4. Выберите русский язык Minecraft.

## Актуальная инвентаризация

Сверка выполнена с официальным репозиторием [AllTheMods/ATM-10](https://github.com/AllTheMods/ATM-10), ветка `main`, ATM10 **8.5**.

- В официальном списке: **497 записей**, **490 уникальных mod ID** (без NeoForge).
- В этом ресурс-паке сейчас: **383 файла `ru_ru.json`**.
- По прямому совпадению mod ID с namespace локализаций покрыто **370 из 490** модов.
- **120 mod ID** пока не имеют одноимённого русского JSON. Это не означает, что все они обязательно требуют отдельного перевода: сначала нужно проверить английские языковые файлы соответствующей версии.
- Ещё **13 namespace** в ресурс-паке не имеют прямого совпадения с mod ID; они сохранены до выяснения их назначения.
- Полный список и методика проверки: [INVENTORY.md](INVENTORY.md).

## Архив прежних переводов

Содержимое Dropbox `languages_ru_ru` проверено и использовано как дополнительный источник. Из него импортированы 23 ранее существовавших файла локализации (включая 20 файлов, добавленных при последней сверке) после проверки английских ключей и плейсхолдеров. Более полные файлы GitHub не заменялись старыми версиями Dropbox. Подробный отчёт и оставшиеся исключения находятся в [INVENTORY.md](INVENTORY.md).

FTB Quests/SNBT намеренно отложен до самого конца проекта.

## Повторная смысловая проверка

Проверка переводов проводится не только по совпадению ключей: названия предметов и блоков сверяются с назначением, рецептами, описаниями и механиками соответствующих модов. Семантическая вычитка всех файлов продолжается; текущий набор не объявляется завершённым.

## Правила качества

- Не менять ключи JSON.
- Сохранять плейсхолдеры (`%s`, `%d`, `%%` и позиционные варианты).
- Сохранять форматирующие коды Minecraft (`§`).
- Сохранять технические идентификаторы, namespace и названия API.
- Не изменять SNBT до отдельной проверки структуры и ссылок FTB Quests.
- Каждый импортированный или переведённый файл сверять с английским оригиналом: ключи, плейсхолдеры и форматирование.
