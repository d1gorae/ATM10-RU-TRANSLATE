# FTB Quests — ATM10 RU

Перевод заданий ATM10. Файлы SNBT устанавливаются отдельно от ресурс-пака.

## Установка вручную

Скопируйте содержимое папки `ru_ru` в:

```
config/ftbquests/quests/lang/ru_ru/
```

Путь указан относительно папки экземпляра ATM10. Перед заменой собственных файлов сделайте резервную копию.

## Структура

- `ru_ru/chapter.snbt` — названия глав.
- `ru_ru/chapter_group.snbt` — группы глав.
- `ru_ru/reward_table.snbt` — таблицы наград.
- `ru_ru/chapters/` — переводы отдельных глав.

Для обычной установки используйте единый архив из [Releases](https://github.com/d1gorae/ATM10-RU-TRANSLATE/releases/latest): он уже содержит файлы FTB Quests по правильному пути.
